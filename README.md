# Projets de C# - 2023 à 2025

Ce dépôt regroupe tous les projets réalisés dans le cadre de mes études en C# de 2023 à 2025. Vous trouverez ici une collection de mes travaux, incluant des applications variées allant de la gestion de bases de données à la création d'interfaces utilisateur avec WPF, ainsi que des projets orientés vers la gestion de stocks, la création de jeux, et bien plus.

## Installation

Pour chaque projet, voici les étapes d'installation :

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/AzmogEx/COURS-CSHARP.NET-2023-2025.git
   ```

2. Ouvrir le projet dans **Visual Studio** (ou un autre IDE compatible avec C# et WPF).
3. Restaurer les packages NuGet nécessaires.
4. Lancer l'application directement depuis l'IDE.
